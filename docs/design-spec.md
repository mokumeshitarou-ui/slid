# デザイン仕様書

## キャンバス

| 項目 | 値 |
|---|---|
| 解像度 | 1920 x 1080 px |
| アスペクト比 | 16:9 |
| 安全領域 | 上下左右 7%（上下76px、左右134px） |
| 最小視聴環境 | スマホ横画面 |

## タイポグラフィ

| 項目 | 値 |
|---|---|
| フォント優先順 | Noto Sans JP > Yu Gothic > Hiragino Sans |
| 最小フォントサイズ | **32px（厳守）** |
| 推奨本文サイズ | 34-40px |
| タイトルサイズ | 56-72px |
| 見出しサイズ | 44px |

**32px未満のテキストは一切存在してはならない。**
情報が入りきらない場合は、フォントを小さくせずに枚数を増やす。

## 装飾ルール

### 許可

- 矩形背景によるセクション分け
- 太線（3px以上）によるボーダー
- 背景色の切り替え（白/グレー/ダーク）
- テキストの太字・色変更

### 禁止

- 写真
- イラスト
- アイコン（テキストアイコンも含む）
- 細線（3px未満）
- 絵文字
- 機種依存文字
- 特殊記号フォント

## テンプレート別仕様（6種）

### 1. タイトル（title.html）

- 背景: ダーク紺 `--bg-primary`
- L字フレーム: 左上＋右下に金色120px角の枠線（4px）
- 店名: 80px 白 太字 中央揃え
- 区切り線: 160px 金色 4px
- エリア: 40px サブテキスト色
- ジャンルサブ: 32px グレー 大文字

### 2. 店情報（shop-info.html）

- 2カラム: 左=営業時間 / 右=アクセス・住所
- ヘッダー: 共通ページヘッダー「店舗情報・営業時間」
- カード: `--bg-card` 背景、ボーダー1px
- 営業時間ブロック: 金縦棒4px + ラベル36px + 時間48px太字
- 定休日: 中央揃え、44px太字
- 情報カード: ラベル32pxグレー + 値36px白

### 3. メニューリスト型（menu.html）

- ヘッダー: 共通ページヘッダー
- カテゴリブロック: カード内に金縦棒4px + カテゴリ名40px
- メニュー項目: 名前36px + 点線リーダー + 価格36px太字
- 注記: 32px サブテキスト色
- 限定: 金背景ラベル 32px太字
- 要確認: 赤文字 32px太字
- 税表記: 32px グレー 右揃え
- レイアウト: **2カラム基本**、1カラム6-7項目目安

### 4. メニューグリッド型（menu-grid.html）

- ヘッダー: 共通ページヘッダー
- グリッド: 3x2 / 2x2 / 2x3 のバリエーション
- カード: 中央揃え、名前40px太字 + 説明32px + 価格48px太字
- セットメニュー: 左アクセント枠カード、ラベル金色 + 名前38px + "+200円"表示
- トッピング・サイドメニューに使用

### 5. エンディング（ending.html）

- 「ご来店お待ちしています」56px 白 中央
- 金区切り線: 120px 3px
- 下部: 店名ローマ字 34px 金色 + "THANK YOU FOR WATCHING" 32px グレー
- 上下に控えめ水平線

### 6. 要確認スライド（menu.htmlベースで構成）

- ヘッダー: 共通ページヘッダー
- リスト形式: 各項目の問題点と元画像の位置ヒント
- 注意枠: `--warning`色ボーダー3px

## 破綻防止ルール

| ケース | 対応 |
|---|---|
| メニュー項目が多い | カテゴリを複数スライドに分割。"カテゴリ名 (1/N)" 表記 |
| 注記が長い | 別行で折返し。省略禁止 |
| 価格が複数（S/M/Lなど） | price_text をそのまま1行で表示 |
| 不明/読取不可 | 「要確認」を赤文字で明示 |
| 店情報に矛盾 | 注意枠で「情報に差異あり」として併記 |
| overflow発生 | items_per_slide を減らして再分割→再レンダ |

## overflow自動修正

```
レンダリング後にDOM検査:

1. element.scrollHeight > element.clientHeight を全要素で検査
2. overflow 検出 → 該当カテゴリの items_per_slide を 1 減らす
3. 再分割 → 再レンダリング → 再検査
4. overflow なし → 確定
```

この仕組みにより「フォント固定 + 自動再分割」で崩れを設計レベルで根絶する。
