# デザイン仕様書

## キャンバス

| 項目 | 値 |
|---|---|
| 解像度 | 1920 x 1080 px |
| アスペクト比 | 16:9 |
| 安全領域 | 上下左右 7%（上下76px、左右134px） |
| 最小視聴環境 | スマホ横画面 |

## タイポグラフィ

| 項目 | 値 |
|---|---|
| フォント優先順 | Noto Sans JP > Yu Gothic > Hiragino Sans |
| 最小フォントサイズ | **32px（厳守）** |
| 推奨本文サイズ | 34-40px |
| タイトルサイズ | 56-72px |
| 見出しサイズ | 44px |

**32px未満のテキストは一切存在してはならない。**
情報が入りきらない場合は、フォントを小さくせずに枚数を増やす。

## 装飾ルール

### 許可

- 矩形背景によるセクション分け
- 太線（3px以上）によるボーダー
- 背景色の切り替え（白/グレー/ダーク）
- テキストの太字・色変更

### 禁止

- 写真
- イラスト
- アイコン（テキストアイコンも含む）
- 細線（3px未満）
- 絵文字
- 機種依存文字
- 特殊記号フォント

## スライド種類別仕様

### 1. タイトルスライド

- 店名: 72px 太字 中央揃え
- エリア: 44px 中央揃え
- 区切り線: 太線（4px, 幅200px）

### 2. 店情報スライド

- ヘッダー: 44px 太字 + 下線（4px）
- ラベル: 34px 太字 グレー背景
- 値: 36px
- 矛盾情報: 注意枠（オレンジ枠 3px）

### 3. メニュースライド

- カテゴリ名: 44px 太字 ダーク背景白文字
- ページ表記: 34px（カテゴリ名の隣に "(1/4)" 等）
- メニュー名: 36px
- 価格: 36px 太字 右揃え
- 注記: 32px グレー文字
- 限定表示: 32px オレンジ背景白文字ラベル
- 要確認: 32px 赤太字
- 税表記: 32px 右揃え グレー文字
- レイアウト: **2カラム基本**、1カラム6-7項目目安

### 4. 要確認スライド（オプション）

- ヘッダー: 44px 太字
- リスト形式: 各項目の問題点と元画像の位置ヒント

## 破綻防止ルール

| ケース | 対応 |
|---|---|
| メニュー項目が多い | カテゴリを複数スライドに分割。"カテゴリ名 (1/N)" 表記 |
| 注記が長い | 別行で折返し。省略禁止 |
| 価格が複数（S/M/Lなど） | price_text をそのまま1行で表示 |
| 不明/読取不可 | 「要確認」を赤文字で明示 |
| 店情報に矛盾 | 注意枠で「情報に差異あり」として併記 |
| overflow発生 | items_per_slide を減らして再分割→再レンダ |

## overflow自動修正

```
レンダリング後にDOM検査:

1. element.scrollHeight > element.clientHeight を全要素で検査
2. overflow 検出 → 該当カテゴリの items_per_slide を 1 減らす
3. 再分割 → 再レンダリング → 再検査
4. overflow なし → 確定
```

この仕組みにより「フォント固定 + 自動再分割」で崩れを設計レベルで根絶する。
