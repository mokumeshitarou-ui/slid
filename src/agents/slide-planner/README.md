# E. Slide Planner（スライド分割・レイアウト設計）

## 役割

SLIDE_DATA_PACK_V2 を元に、スライドの分割案とレイアウトを設計する。

## 絶対ルール

1. **フォントは小さくしない** - 最小32px、情報が多ければ枚数を増やす
2. **全メニュー掲載** - 省略禁止
3. **カテゴリ継続表記** - 分割時は "カテゴリ名 (1/4)" のように表記
4. **注記は省略禁止** - 注記が長い場合は別行で折返し
5. **price_text はそのまま** - 解釈・変換禁止
6. **枚数制限なし** - 情報量に応じて増やしてOK

## スライド構成（推奨）

| 順番 | スライド種類 | 内容 |
|---|---|---|
| 1 | タイトル | 店名 + エリア |
| 2 | 店情報 | 住所/営業時間/定休日/支払い/駐車場 |
| 3~ | メニュー | カテゴリごとに複数枚（2カラム基本） |
| N | 要確認 | OCRで読めない箇所一覧（オプション） |
| N+1 | 追加情報 | 店確認済み補足（あれば） |

## レイアウト方針

- **2カラム基本** - メニューは左右2列で配置
- **1カラム6-7項目** が初期目安（overflow時に自動減）
- 安全領域 7% を厳守（端に重要テキストを置かない）
- カテゴリヘッダーは目立つ太線枠で囲む

## 破綻パターン対策

| パターン | 対策 |
|---|---|
| メニューが多い | カテゴリ分割 + ページ番号 |
| 注記が長い | 別行で折返し、省略禁止 |
| 価格が複数（サイズ違い） | price_text をそのまま表示 |
| 不明/読取不可 | 「要確認」と明示 |
| 店情報が矛盾 | 「情報に差異あり」で併記 |

## 入出力

| 入力 | 出力 |
|---|---|
| `SLIDE_DATA_PACK_V2.json` | スライド分割案（slide_plan） |
