# Discord Bot

## 概要

1店舗 = 1スレッドでスライド生成を管理する Discord Bot。

## スラッシュコマンド

| コマンド | 説明 | パイプライン |
|---|---|---|
| `/run` | このスレッドの画像で一括実行 | 全ステップ |
| `/status` | 抽出件数・要確認・矛盾・最終更新 | 参照のみ |
| `/confirm` | 店確認済み情報を追加 | Pack Builder以降を再実行 |
| `/render` | データパックから再レンダリング | Planner + Renderer + QA |

## 進捗メッセージ

Bot はパイプライン実行中に以下のステータスを投稿する:

1. 「画像を収集中...（N枚検出）」
2. 「OCR抽出中...」
3. 「店舗情報を調査中...」
4. 「データを統合中...」
5. 「スライドを設計中...」
6. 「レンダリング中...」
7. 「品質チェック中...」
8. 「完了 - N枚のスライドを生成しました」

## 完了時の投稿内容

- `slides.zip`（添付ファイル）
- QA結果サマリー（PASS/FAIL）
- メニュー掲載数
- 要確認項目（あれば）
- 矛盾情報（あれば）

## 環境変数

```
DISCORD_BOT_TOKEN=（Bot トークン）
```

## 権限

- メッセージ送信
- ファイル添付
- スレッド内メッセージ読み取り
- スレッド内添付ファイル読み取り
- スラッシュコマンド登録
